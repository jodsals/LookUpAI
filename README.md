# LookUpAI
Dieses Projekt entwickelt ein KI-basiertes Agentensystem, das Listen von Geschäftspersonen analysiert und daraus aktuelle, konsistente sowie überprüfte Faktenblätter erstellt. Ziel ist es, Vertriebs- und Rechercheprozesse zu unterstützen, indem automatisch die Echtheit von Personen und deren Unternehmenszugehörigkeit geprüft werden.
